
# Analisis Komparatif Platform

| Aspek | Web | Desktop | Mobile |
|---|---|---|---|
| Bahasa utama | HTML, CSS, JavaScript, TypeScript | C++, C#, Java, Python | Kotlin, Java, Swift, Dart |
| Arsitektur | Umumnya client-server, diakses melalui browser | Aplikasi terinstal yang berjalan pada sistem operasi | Aplikasi yang berjalan pada sistem operasi mobile |
| Cara distribusi | Melalui URL menggunakan browser | Installer, paket aplikasi, atau toko aplikasi | Google Play Store, Apple App Store, atau metode distribusi lain |
| Keunggulan | Mudah diakses, tidak perlu instalasi langsung, pembaruan terpusat | Integrasi sistem operasi dan akses sumber daya lokal | Portabel, mendukung layar sentuh, kamera, GPS, dan sensor |
| Keterbatasan | Bergantung pada browser dan jaringan untuk fitur tertentu | Perlu memperhatikan kompatibilitas OS dan instalasi | Memperhatikan baterai, ukuran layar, dan perbedaan perangkat |
| Contoh aplikasi | Gmail Web, Google Docs Web | Visual Studio Code, Microsoft Word Desktop | WhatsApp Mobile, Google Maps |
